# Invariants

* [A batch is at most 49 envelopes, admitted whole or not at all](a-batch-is-at-most-49.md) - The gate's batch is one transaction and one anam-time instant; the daemon refuses more than 49 with 400 and the importer base cuts at 49.
* [A registered Definition version is immutable](registered-definition-is-immutable.md) - Once held, a version's body never changes; the operational store's triggers refuse update and delete, and a different body at a held version is a 409.
* [A type lives in one place](a-type-lives-in-one-place.md) - While the binary bundles a type no importer may register it and any number may submit it; an importer takes a type over when a release drops it; two importers naming an unbundled type refuse the daemon's start.
* [Admission is three pillars through the one gate](three-pillar-admission.md) - Facet-compliant (the Definition's closed schema and time semantics), authenticated (the source's token scope), associated (bound to the person with assurance); nothing enters except through resolve then commit.
* [Agent findings are derived facets admitted as proposed; endorsement never writes back](endorsement-never-writes-back.md) - An insight re-enters through the same gate as a proposed derived facet carrying its method and the watermark it was computed from; endorsed and rejected are anam-events that never reach a source.
* [An importer never tombstones; the operator retracts](an-importer-never-tombstones.md) - There is no automatic retraction: an importer reports what its source still holds through a snapshot, and only anam retract, with guards and --yes, writes a tombstone.
* [An importer shapes payloads and nothing else](importers-shape-only.md) - No identity, no joins, no summaries, no state of the record, no token; an envelope names no source and no source_ref.
* [Anam owns no source fact](owns-no-source-fact.md) - No captured payload exists only inside Anam; every one is verbatim from its source and rebuildable, so deleting Anam loses no fact. Anam does own the continuity.
* [Any state is the nearest checkpoint plus replay since its watermark](any-state-is-checkpoint-plus-replay.md) - A read at W equals the fold at W whether it is composed from the last run's checkpoints and the tail or folded from seq 0; the composed read is tested equal to the fold at every watermark.
* [Append-only is enforced by the ledger's triggers, for every writer](append-only-enforced-by-triggers.md) - Facts are added and re-statused, never modified, never deleted; triggers on every ledger table refuse UPDATE, DELETE and an INSERT over an existing key, binding a sqlite3 shell as much as Anam.
* [Canonical means the live-only value; the ledger means append-everything-marked](canonical-means-live-only.md) - One word, one surface: the canonical is the fold's live facets at a watermark, superseded and tombstoned ones excluded from the value and retained in the ledger, marked.
* [commit is idempotent and atomic](commit-is-idempotent-and-atomic.md) - Artifact, anam-event and watermark land in one transaction in one file; same identity and same hash is a no-op, a different hash supersedes, and a refused batch writes nothing, so a worker may crash mid-batch and be re-run to known-good.
* [Current status is derived by the fold, never stored on the artifact](status-is-derived-never-stored.md) - A facet carries its birth status and nothing else; admitted, superseded, tombstoned, endorsed and rejected are folded from anam-events on every read.
* [Each route names the roles it admits](each-route-names-the-roles-it-admits.md) - The daemon's one route table lists, per route, the roles whose tokens open it; no handler checks who a caller is, so a route a role may not use is a 403 before any work is queued.
* [Every external call carries a deadline and fails fast](external-calls-fail-fast.md) - Every store method takes a context with a deadline; every daemon write runs under its job's deadline; a missing ledger is an error on open, never created by reading.
* [Metadata and payload are separated; the payload is opaque](metadata-payload-separation.md) - Anam governs and projections filter on the facet's attributes and descriptor; the payload is verbatim, immutable, stored as bytes and never parsed into a canonical schema.
* [Minting is per span, never whole-life](minting-is-per-span-never-whole-life.md) - A checkpoint is the value of one bucket at a watermark; the lifelong view composes bucket values and never re-folds the person.
* [Only internal/store may name SQLite or database/sql](only-store-names-sqlite.md) - The substrate is accidental; scripts/check.sh fails the build if database/sql or sqlite is imported outside internal/store, with no carve-out since card 119.
* [Projections prune, never reshape or generate; a consumer selects, never defines](projections-prune-never-reshape.md) - A template includes or excludes whole facets by metadata filters only, and the only templates are the versioned ones bundled in the binary.
* [Queue wait spends the caller's budget up to acceptance](queue-wait-spends-the-callers-budget.md) - A request's whole time is the shorter of the daemon's timeout and the caller's Anam-Timeout; waiting for the write queue spends it, a write whose caller has gone or whose budget is spent never starts, and an accepted write is reported as it happened.
* [Sort keys are identity-first, and integers are typed](sort-keys-are-identity-first-and-typed.md) - An artifact's key carries facet_id then artifact_version, never fact_time; version and seq are INTEGER columns so they order numerically; times are fixed-width UTC text.
* [source_ref is identity; content_hash is content](source-ref-is-identity-content-hash-is-content.md) - The natural key never contains a row's values, or supersession silently becomes duplication; the gate composes identity from identity_key and refuses an envelope that disagrees.
* [The bucket width is checked once at config load and pinned into the index](bucket-width-is-checked-once-and-pinned.md) - span.New is the only constructor and refuses an unknown width at startup; the operational store pins the width it was built at and refuses a file built at another, so changing it is a rebuild, not a migration.
* [The derived tier must stay provably rebuildable from the ledger](derived-tier-is-provably-rebuildable.md) - The ledger is the system of record; the library's files hold documents; the operational store's derived tables come back by replay and must never acquire a second home for a payload, an event or W.
* [The Envelope is the only ingress](envelope-is-the-only-ingress.md) - Importers share nothing with the ledger except through an envelope posted to the daemon; only an importer's token opens the submit routes, and since card 119 no code in the binary reads a source.
* [The ledger carries no secondary indexes](ledger-carries-no-secondary-indexes.md) - An index is derived, and derived things live in the operational store; the ledger serves two access paths, both on a primary key.
* [The whole-person read is the default; a span is an optional lens](whole-person-read-is-the-default.md) - Storage is partitioned by the person onto one timeline; no span is required to read, and a derived span only narrows a read.
* [W is the anam-event sequence itself: one number, gapless, never stored](w-is-the-event-sequence.md) - The watermark is MAX(seq); a trigger lets an event take only the next seq; every event kind advances it, a pure status transition included.
* [What Anam authors is authored, never authoritative](authored-never-authoritative.md) - Governing metadata, the ledger order, watermarks, checkpoints, receipts and provisional derived findings are Anam's own operational record: backed up, never rebuilt from a source, never the truth about the world.
